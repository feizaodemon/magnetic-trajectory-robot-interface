    How it works

    1. Normalize. All strokes are joined, centered on their centroid, scaled by the largest coordinate and resampled to 64 points by arc length.
    2. Compare. Dynamic time warping against every template; each symbol scores its closest template.
    3. Gate. The top symbol is accepted only if its distance is at most , it beats the runner-up by at least , and its confidence (1 − distance / max distance) is at least . Otherwise the robot side shows the drawing as uncertain and offers nothing.
    4. Confirm. On the robot an accepted symbol is still only a proposal: the operator must confirm it before the matching task runs.

    The templates come from one person's mouse drawings, so the recognizer is tuned to that writer; other handwriting can be rejected more often. The JavaScript port is checked against the Python code in CI (tests/test_web_recognizer_parity.py).
